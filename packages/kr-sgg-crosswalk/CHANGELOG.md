# 변경 내역

## v0.3.0 (2026-10-23)

다시 만든 근거: 행정안전부 행정기관코드 변경내역(말소코드 포함)의 단위 레지스트리와 공식 변경 사건. 만드는 코드는 저장소의 `scripts/region_registry/`에 있다.

### 고친 것
- **기초 단위 228개 → 229개.** v0.2는 시 코드를 `sggcd[:4] + "0"`으로 만들어 증평군(43745)이 영동군에 합쳐졌고, 끝자리가 0이 아닌 자치구 8곳(광진 11215, 강북 11305, 금천 11545, 미추홀 28177, 연수 28185, 부평 28237, 계양 28245, 광주 남구 29155) 코드가 틀렸다. v0.3은 코드를 자르지 않고 레지스트리의 소속 관계를 쓴다.
- **부천 일반구.** 2016 폐지·2024 부활로 같은 이름의 구가 돌아왔다. v0.2는 이름이 같아 1:1로 이었다. v0.3도 원미구 2010 → 원미구 2025가 99.8%로, 경계를 겹쳐 확인한 값이다.
- **변경 판정.** v0.2는 경계판 비교로 변경을 추정했다. v0.3은 공식 시행일과 사건(재부여·명칭 변경·통합·분할·흡수·개편)으로 판정하고, 경계는 몫 계산에만 쓴다.

### 더한 것
- 2008·2009년(v0.2는 2010년부터).
- 인구 가중 `w_src_pop`, `w_tgt_pop`과 `harmonize(weights="pop")`.
- 통계청 코드 `src_kostat`, `tgt_kostat`과 `harmonize(code_system="kostat")`.
- 10자리 행안부 코드 `src_code10`, `tgt_code10`.
- 연도별 단위 목록 `units/`, 일반구 → 기초 단위 합치기 `to_lgu()`.
- 공식 변경 사건 `crosswalk/events_{lgu,sgg}.csv`. v0.2의 `change_summary_*.csv`를 대신한다.
- `manifest.json`(만든 날, 원자료 판, 파일 해시).

### 바뀐 것
- `method` 값: `code_1to1`, `code_changed_whole`(v0.2의 `code_renumbered_same_name`과 통째로 옮겨지는 통합), `area_split`(v0.2의 `area_abolished_code`·`area_ceded_to_new` 중 실제로 나뉜 것).
- `src_version` 열 대신 `layer_date`(단위 기준일). 경계판은 `units/`의 `boundary_version`.
- 시도 이름은 그 해 이름이다(예: 2015 강원도, 2025 강원특별자치도).
- 경계 GPKG는 패키지에서 빼고 GitHub Release로 배포한다.

### 그대로인 것
- 면적 몫: v0.2와 겹치는 2010–2025년 3,656행에서 차이 0(증평·영동 버그 행과 v0.2의 2% 미만 조각 3행 제외).
- 잡음 제거 규칙(폭 20m 미만 띠, 0.2%·5,000㎡ 미만 조각, 기존 단위로 가는 5% 미만 조각). 새 단위로 가는 조각 기준만 1%로 정했다(청원군 → 세종 3.4%).
