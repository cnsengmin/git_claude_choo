# sgis-grid

SGIS 100m 격자 통계를 벡터 타일로 줍니다. 인구는 2015–2024년이고, 가구·주택·사업체·종사자는 2015·2020·2024년입니다.

- 경로: `GET /api/layers/sgis-grid/grid/<z>/<x>/<y>.pbf`(z11–14), `GET /api/layers/sgis-grid/grid/metadata`.
- 레이어: `people/population-100m`. 사이드바의 "격자 지표"에서 주제와 연도를 한 번에 고릅니다(예: 인구 2024년, 종사자 2020년). 값은 격자 하나(1ha)당 수입니다.
- 자료: GitHub Release `grid-100m-20261030`의 `kr-grid-100m.pmtiles`.
  - `scripts/region_registry/build_release_grid_pmtiles.py`가 `data/raw/sgis/grid/100m`에서 만듭니다. 원자료는 SGIS 자료신청 90231이고 기록은 `data/manifests/sgis-request-90231.json`입니다.
  - 격자 정사각형은 격자 코드에서 계산합니다. `다사526528`이면 앞 두 글자가 100km 구역(x는 가=700000, y는 가=1300000부터 100km씩), 뒤 여섯 자리가 x·y 100m 칸입니다(EPSG:5179).
  - 속성: `cell`(격자 코드), `p<연도>`(인구), `h<연도>`(가구), `u<연도>`(주택), `b<연도>`(사업체), `w<연도>`(종사자).
- 값이 없는 칸: 그 해 SGIS 파일에 없는 격자는 속성을 비워 두고 그리지 않습니다. 0인 격자는 회색으로 칠합니다.
- 비밀보호: SGIS 격자 값에는 1–4가 없고 5·8·13이 몰려 있습니다. 작은 값을 바꿔 공개한 것이라 격자 인구 합계가 인구총조사 총인구보다 2% 안팎 큽니다(2024년 52,926,835명 대 51,805,547명). 격자는 분포를 보는 데 쓰고, 지역 합계는 집계구(`sgis-oa`)나 시군구 통계를 씁니다.
- 사업체·종사자는 SGIS가 100km 구역 '라다' 파일을 주지 않아 29개 구역입니다.
- 라이선스: 공공누리 제1유형(출처표시). 출처: 국가데이터처 SGIS 격자 통계(인구주택총조사·전국사업체조사).
- 읽는 방식은 `sgis-oa`와 같습니다(`layers/providers/pmtiles.ts`). 개발할 때는 `GRID_100M_PMTILES_DIR`(예: `dist/grid-100m`)로 로컬 파일을 읽습니다.

## 확인
`node scripts/layers/check-live.mjs http://localhost:3000 sgis-grid`

2026-10-30 기준:
- **실시간 검사:** 3건 통과(메타데이터, 서울시청 z14 타일, 서울 z11 타일).
- **빌드 대조:** 22개 주제·연도마다 타일에 쓴 격자 수와 합계가 원자료와 같습니다(예: 인구 2024년 1,088,760칸, 52,926,835명).
- **타일 누락 검사:** 서울 시청·부산 서면·제주시의 z11·z12·z14 타일에서 2024년 인구 격자가 하나도 빠지지 않았습니다.
- **위치:** 격자 중심점을 2025 집계구에 겹쳐 시도별로 더하면 서울 1.000, 광역시 1.002–1.010배로 집계구 인구와 맞습니다. 도 지역은 1.01–1.08배인데, 작은 값을 올려 공개한 격자가 많기 때문입니다.
- **지도:** 안양 부림동 다사533341을 누르면 2024년 인구 74명, 가구 52가구, 사업체 11개, 종사자 36명이 원자료와 같게 나옵니다(주택은 그 해 파일에 없음). z11 서울 도심 타일은 약 1.4MB입니다.
