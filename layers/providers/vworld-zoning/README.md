# vworld-zoning

전국 용도지역(도시·관리·농림·자연환경보전 21종)과 개발제한구역을 벡터 타일로 줍니다.

- 경로: `GET /api/layers/vworld-zoning/zoning/<z>/<x>/<y>.pbf`(z9–14), `GET /api/layers/vworld-zoning/zoning/metadata`.
- 레이어: `planning/zoning`. 사이드바의 "용도지역 보기"에서 용도지역 21종, 대분류 4종, 개발제한구역 중 하나를 고릅니다.
- 자료: GitHub Release `zoning-20261030`의 `kr-zoning.pmtiles`(Release 공개 여부는 아래 라이선스 항목을 보고 정합니다).
  - 수집: `scripts/vworld/harvest_data_api.py`가 VWorld 2D 데이터 API(`LT_C_UQ111`–`UQ114`, `LT_C_UD801`)를 전국 범위로 페이지마다 받습니다. 키만 있으면 되고 로그인은 필요 없습니다. 기록은 `data/manifests/vworld-data-api-20261030.json`입니다.
  - 빌드: `scripts/vworld/build_zoning_pmtiles.py`. 페이지마다 영수증의 SHA-256을 확인하고, VWorld가 보고한 건수와 받은 건수가 다르면 멈춥니다.
  - 속성: `zid`(VWorld 도형 id), `kind`(urban·management·agri·conservation·gb), `uname`(VWorld 용도지역명), `name`(표시 이름), `rank`(0 미분류·기타, 1 세부 용도지역, 2 개발제한구역), `dyear`·`dnum`(고시년도·번호), `sido_name`, `sigg_name`.
- 개발할 때는 `ZONING_PMTILES_DIR`(예: `dist/zoning`)로 로컬 파일을 읽습니다.

## 수집 경로를 API로 정한 이유

VWorld 공간정보 다운로드(용도지역지구정보 SHP, 월간 전체본)는 로그인 세션이 있어야 파일을 줍니다. 로그인 없이 요청하면 서버가 빈 파일(0 B)을 돌려줍니다. data.go.kr의 `국토교통부_(연속주제)_*` 자료는 같은 VWorld 다운로드 페이지로 연결됩니다. 그래서 2026-10-30에는 키만으로 되는 2D 데이터 API로 받았습니다.

- 한 번에 최대 1,000건이라 전국 594,666건에 약 600번 호출했습니다.
- 일일 호출 한도는 문서에 숫자가 없고 `OVER_REQUEST_LIMIT` 오류만 적혀 있습니다. 수집 스크립트는 이 오류에서 멈추고, 다시 실행하면 받은 페이지를 건너뛰고 이어서 받습니다.
- 매월 갱신되는 자료를 한 시점(2026-10-30)에 받은 것입니다. 다시 받으면 도형 id(`zid`)와 건수가 달라질 수 있습니다.

## 알려진 문제

**라이선스가 확정되지 않았습니다.** VWorld 다운로드 페이지에는 "라이선스가 지정되어 있지 않습니다"(무상공급)라고 나옵니다. 그런데 data.go.kr에 올라온 같은 연속주제도(예: `국토교통부_(연속주제)_국토계획 도시지역`)는 이용허락범위가 공공누리 제4유형(출처표시·상업적 이용금지·변경금지)입니다. 타일로 바꿔 공개 Release에 올리는 것이 "변경금지"에 걸리는지 확인하기 전까지는 로컬 타일로만 씁니다.

**행정구역 경계와 맞지 않습니다.** 도시지역 도형 60,366건(이름 있는 것)을 2025-12-31 시군구 경계 229개에 겹친 결과는 다음과 같습니다.

| 항목 | 결과 |
|---|---|
| 이웃 시군구로 넘어간 면적 | 409 km², 2.4% |
| 시군구 경계에 걸친 도형 | 2,682건(4.4%). 1 ha 넘게 넘어간 것 1,508건, 1,000 m² 미만 조각 454건 |
| 어느 시군구에도 속하지 않는 면적 | 253 km²(해안·바깥 경계) |
| VWorld `sigg_name`이 면적이 가장 큰 시군구와 같은 비율 | 85.4% |

원인은 세 가지입니다.
- **결정 단위:** 용도지역은 시 단위로 결정되어 `sigg_name`이 "용인시"처럼 시 이름이고, 도형 하나가 여러 자치구에 걸칩니다. 이름 불일치 상위가 용인·창원·고양·천안·세종입니다.
- **시점:** 용도지역은 수집일 현재 자료라 `sigg_name`에 2026년 개편 뒤 이름(인천 영종구·서해구)이 들어 있습니다. 저장소 경계는 시점별(2008–2026)입니다.
- **바탕선:** 용도지역은 지적선을 따르고, 저장소의 행정구역 경계는 SGIS·행안부 경계 파일입니다. 경계선과 해안에서 조각이 생깁니다.

그래서 다음처럼 씁니다.
- 지도에서는 행정경계로 자르지 않고 따로 겹쳐 그립니다.
- 시군구·행정동별 집계에는 `sigg_name`을 쓰지 않고, 저장소의 시점별 경계와 겹쳐 면적 비율로 나눕니다.
- 더 맞추려면 지적 기반인 VWorld 행정구역(`LT_C_ADSIGG_INFO`, `LT_C_ADEMD_INFO`)을 다리로 쓰고, VWorld 코드와 저장소 코드는 명시적 대응표로 잇습니다(아직 하지 않음).

**이름이 빈 도형과 미분류 도형이 있습니다.**
- 도시지역 중 `uname`이 빈 도형 210건(2,985 km²)은 면적의 95%(2,836 km²)가 이름 있는 용도지역과 겹칩니다. 도시지역 바깥 경계로 보고 "도시지역(세부 미분류)"로 이름 붙여 `rank` 0으로 아래에 그립니다. 겹치지 않는 149 km²(대전 동구 103 km² 등)는 세부 용도지역이 빠진 곳일 수 있지만 확인하지 않았습니다.
- `도시지역기타` 885건(0.6 km²), `도시지역미지정` 224건(129 km²), `도시지역미분류` 33건, `관리지역미분류` 284건 등도 `rank` 0입니다.
- `일반주거지역`(28건), `공업지역`(2건)처럼 세분되지 않은 옛 이름이 조금 있습니다. 범례 색이 없어 회색으로 그려집니다.

**도형 품질.** 잘못된 도형(자기 교차 등)이 6,130건(도시 191, 관리 2,483, 농림 3,433, 자연환경보전 19, 개발제한구역 4) 있어 `make_valid`로 고쳤습니다. 고친 뒤 선·점만 남은 조각은 버렸고, 그래서 사라진 도형은 없습니다(594,666건 모두 타일에 들어감).

**면적 합계가 국토 면적보다 큽니다.** 개발제한구역은 다른 용도지역 위에 겹치는 구역이고, 이름 빈 도시지역 도형도 세부 용도지역과 겹칩니다. 자료별 면적 합(도시 20,105, 관리 27,364, 농림 49,465, 자연환경보전 9,979, 개발제한구역 3,751 km²)은 그대로 더하면 안 됩니다. 공식 도시계획현황 통계와는 아직 대조하지 않았습니다.

**고시 정보가 비어 있는 경우가 많습니다.** `dyear`·`dnum`이 `0000`이면 고시년도·번호를 모르는 것입니다. 팝업에서는 표시하지 않습니다.

**전국이 한눈에 보이는 줌(z7–8)에서는 쓸 수 없습니다.** 처음 z7–14로 만든 타일을 원자료와 대조해 보니, 서울을 덮는 z7 타일에는 원자료 219,982건 중 92,459건만 들어 있었습니다(면적의 40% 누락, 232 km²짜리 도형까지 빠짐). z8 타일은 면적의 31%가 빠졌습니다. 타일 하나의 크기·건수 한도(2 MB) 때문입니다. 그래서 z9부터만 만듭니다. z9부터 다시 만든 타일(454.5 MB)을 서울·홍천·부산·제주·안양 타일로 대조하면, 빠지는 도형은 화면에서 한 픽셀이 안 되는 조각뿐입니다(z9 최대 4,194 m²·99%가 1,618 m² 미만, z11 최대 158 m², z12·z14 누락 없음). 면적으로는 0.01% 이하입니다. 전국 보기용 저배율 타일이 필요하면 시군구별로 합친 도형을 따로 만들어야 합니다(아직 하지 않음).

**법적 효력이 없습니다.** VWorld는 이 자료를 정보 제공용으로 안내합니다. 개별 필지의 용도지역 확인은 토지이음의 토지이용계획확인서를 써야 합니다.

- 라이선스 표기: 출처 국토교통부 용도지역지구정보(VWorld). 위 라이선스 문제를 정리하면 고칩니다.

## 확인
`node scripts/layers/check-live.mjs http://localhost:3000 vworld-zoning`

2026-10-30 기준(로컬 타일, `ZONING_PMTILES_DIR`):
- **실시간 검사:** 3건 통과(메타데이터 z9–14, 서울시청 z14 타일, 서울 z10 타일 888 KB).
- **빌드 대조:** 다섯 자료 모두 VWorld가 보고한 건수(합계 594,666)를 타일에 썼고, VWorld 도형 id 중복이 없습니다. 파일 454.5 MB.
- **타일 누락 검사:** 위 "전국이 한눈에 보이는 줌" 항목 참고. z9–14에서는 한 픽셀 미만 조각만 빠집니다.
- **지도:** 안양 평촌에서 중심상업·일반주거·공업·녹지가 색으로 구분되고, 누르면 "중심상업지역 (도시지역) · 경기도 안양시 동안구"가 시군구 경계 구획과 함께 나옵니다. 대분류 4종·개발제한구역 보기도 바뀝니다. 안양천을 따르는 동안구·만안구 경계선은 이 축척에서 용도지역 경계와 크게 어긋나 보이지 않았습니다(정밀 대조는 하지 않음).
