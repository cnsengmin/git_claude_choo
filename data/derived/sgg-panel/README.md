# 시군구 시계열 2008–2025 (2025 경계 기준)

2025-12-31 기준 단위 229개에 맞춘 연도별 공식통계입니다. 그해 행정구역으로 나온 KOSIS 값을 연결표로 2025 경계에 옮겼습니다. 만드는 방법은 `scripts/sgg_panel/README.md`에 있습니다.

| 파일 | 내용 |
|---|---|
| `lgu229_panel.csv` | 단위 229개 × 2008–2025년 = 4,122행. 변수마다 열 하나이고, 시계열이 시작되기 전 해는 빈 칸입니다. `alloc_share`는 그 단위·연도 값 가운데 나뉜 단위에서 배분받은 몫(변수 중 최댓값)입니다 |
| `panel_check.csv` | 표·연도·변수마다 KOSIS 전국 행, 단위 합, 2025 경계로 옮긴 뒤 합, 연결하지 않은 코드, 시 행과 일반구 합의 차이 |

변수 이름과 정의는 2025 단년 표(`data/derived/sgg2025/codebook.csv`)와 같습니다. 2025년 값은 그 표와 같습니다.

## 쓰기 전에
- **모두 합산형 변수입니다.** 비율은 옮긴 뒤 분자·분모로 다시 계산하세요(예: 출생아 1천 명당 = `births / pop_total × 1000`). 합계출산율처럼 다시 계산할 수 없는 값은 넣지 않았습니다.
- **나눠 배분한 값이 있습니다.** 2012년 세종 출범 전(2008–2011)의 세종, 공주시, 청주시는 연결표의 인구 몫(인구총조사 2015)으로 공주·청원 일부를 나눠 받습니다(`alloc_share` > 0, 12개 단위·연도). 통째로 옮긴 경우(청원 → 청주 2014, 군위 → 대구 2023, 강원·전북 코드 변경, 미추홀구 이름 변경)는 배분이 아닙니다.
- **이동 통계:** 나중에 합쳐진 단위 사이의 이동(예: 2013년 청주시↔청원군)은 합친 단위의 전입·전출에 그대로 남습니다. 순이동은 맞습니다.
- **등록센서스와 주민등록은 다른 개념입니다**(상주 기준, 외국인 포함 여부).
