## 쓰기 전에

- **주민등록인구와 등록센서스 인구는 다른 개념**입니다(센서스는 상주 기준, 외국인 포함). 한 모형에 섞을 때는 변수 이름의 출처를 확인하세요.
- **사업체 자료는 2024년**입니다. 2025년 자료는 아직 공표 전입니다.
- **지역별고용조사는 표본조사**입니다. 시군구 표에는 숫자 RSE가 없고, RSE 25% 이상일 때만 `*`가 붙어 옵니다. 이를 `lfs_*_rse25` 플래그(1=신뢰도 낮음)로 옮겼습니다. 실업자·실업률은 절반 가까운 단위(110·109곳)가 해당합니다. 고용률(15세 이상)은 해당 없음.
- **세종은 지역별고용조사 시군구 표에 없어** 고용 변수가 결측입니다.
- 비율 변수(`rate`, `derived`)는 더하면 안 됩니다. 다른 경계로 옮길 때는 분모 변수로 가중평균하세요.

## 검증 (`python scripts/sgg2025/validate.py`) — 31/31 통과

- 합산형 28개 변수 모두 229개 합 = KOSIS 전국 공표치(차이 0), 시도 합계 476건 = KOSIS 시도 공표치(차이 0)
- 남+여=총인구, 5세 연령군 합=총인구, 전입−전출=순이동, 주택 유형 합=주택 계 등 내부 정합성
- 대응 오류 탐지: 등록센서스/주민등록 인구비 0.90–1.18, 고용조사 15세+/주민등록 15세+ 0.78–1.17(낮은 쪽은 섬·군부대 지역), 고성군 2곳 맞바꿈 검사
- 통계청↔행안부 시군구 252쌍 1:1, 미매칭 코드 0, 산출물·manifest·스크립트·원자료에서 키 문자열 0건
